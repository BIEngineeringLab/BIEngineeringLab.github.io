Power BI DAX Measures: A Practical Beginner Guide

Learn what DAX measures are, why they matter, and how to create useful calculations that respond to filters in a Power BI report.

BI Engineering Lab · August 2026 · 6 min read

DAX, short for Data Analysis Expressions, is the formula language used in Power BI. It lets you create calculations such as total sales, profit margin, year-to-date revenue, and performance comparisons.

What is a measure?

A measure is a calculation evaluated when a visual is displayed. Unlike a fixed value stored in a data table, a measure changes based on filters, slicers, rows, columns, and other context in your report.

Simple example: If a report user chooses 2026 in a Year slicer, a Total Sales measure automatically recalculates to show sales for 2026 only.

Create your first measure

Suppose you have a table called Sales with a column named SalesAmount. Create this measure:

Total Sales
Total Sales = SUM(Sales[SalesAmount])

Add this measure to a Card visual to display total sales. Add it to a chart with Month on the axis, and it will show total sales for each month. The formula remains the same; the visual context changes.

Measures versus calculated columns

A calculated column evaluates row by row when data is refreshed. A measure evaluates at query time, based on the report context.

  • Use a calculated column when you need a value stored for every row.
  • Use a measure for totals, ratios, averages, percentages, and KPIs.
  • Prefer measures for report calculations when possible.

A useful percentage measure

This example calculates profit margin safely. The DIVIDE function avoids an error when total sales are zero.

Profit Margin
Profit Margin =
DIVIDE(
    [Total Profit],
    [Total Sales],
    0
)

Beginner best practices

  • Name measures clearly, such as Total Sales or Customer Count.
  • Format currency, percentages, and whole numbers in the Power BI modeling pane.
  • Keep related measures in a dedicated measures table as your model grows.
  • Start with simple measures before learning advanced functions such as CALCULATE.
  • Test each measure with different filters and slicers.

Next step
